# Thirupur Rockers Studio — Luxury Photography Atelier

An award-level (Awwwards / FWA style) digital atelier and portfolio for **Thirupur Rockers Studio** (Tiruppur, Tamil Nadu).

## Highlights
- **Editorial Design System**: Quiet luxury aesthetic, warm ivory & pure noir dark mode, fine-art typography.
- **Motion & Cinematic Atmosphere**: Aperture shutter preloader, GSAP ScrollTrigger animations, Lenis smooth scroll, magnetic interactive buttons, and custom cursor.
- **Dedicated Portfolios**:
  - Candid Wedding Photography & 4K Cinema
  - Baby, Kids & Newborn Milestone Gallery
  - Maternity Grace & Sacred Family Moments
  - High-Fashion & Model Lookbooks
- **Dual Theme Support**: Warm Ivory and Noir Dark Mode.
- **Seamless Booking**: Interactive package inquiry, direct WhatsApp integration (`+91 90803 35174`), and Instagram feed integration (`@tirupur_rockerss_studio`).

## Tech Stack
- **Core**: React 19, Vite
- **Styling**: Tailwind CSS, Vanilla CSS Design Tokens
- **Animation**: GSAP, Lucide React
- **Deployment**: Production-optimized Vite bundle

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build
```
